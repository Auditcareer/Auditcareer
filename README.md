# Auditcareer — статический сайт об аудите

## Как открыть локально
1. Распакуйте архив.
2. Откройте `index.html` в браузере.

## Как загрузить на хостинг
1. Загрузите все файлы из папки сайта в корневую директорию хостинга (`public_html` или `www`).
2. Убедитесь, что `index.html` находится в корне.
3. Включите HTTPS.
4. Проверьте, что `robots.txt` и `sitemap.xml` доступны по адресу домена.

## Структура
- `index.html` — главная.
- `cases.html` — Audit Practice.
- `tools.html` — Hard Skills.
- `career.html` — Career Center.
- `excel-top-10.html`, `english-foundations.html`, `english-present-tenses.html`, `english-past-simple.html` — статьи Hard Skills.
- `big4-internship-plan.html`, `big4-hard-skills.html` — статьи Career Center.
- `styles.css` — все стили.
- `script.js` — меню и кнопка наверх.
- `assets/` — SVG-иллюстрация и favicon.
- `robots.txt`, `sitemap.xml` — SEO.

## Конфиденциальность
Сайт не собирает контактные данные, не содержит форм и не отправляет данные.
